VideoTranslator Studio

EN → SK automatický video-dubbing pipeline. STT · Preklad · TTS · Assembly.

Funkcie

📁 Lokálny súbor
Preklad z MP4/MKV/AVI s 4-krokovým wizardom (STT → Preklad → TTS → Finalizácia).
⬇️ Stiahnutie videa
YouTube, Vimeo, TikTok, X/Twitter, Facebook a 1000+ ďalších cez yt-dlp.
🎙 Narrátor
Text-to-speech s referenčným hlasom a štýl-instructom (OmniVoice / Chatterbox).
🔧 Nástroje
EQ, QC analýza, tréning vlastných modelov, správa API kľúčov.

Pipeline

  1. STT — Faster-Whisper large-v3-turbo, context-aware
  2. Preklad — Gemma 4 26B fine-tuned (SK), sliding-window batching
  3. Text adaptácia — slot-aware rewrite, adaptívna CPS kalibrácia
  4. TTS — OmniVoice (primary, zero-shot 600+ jazykov) alebo Chatterbox SK 2.2
  5. Assembly — preserve gaps, sync-safe timeline

Hardware

Optimalizované pre RTX 4090 (24 GB VRAM), Linux, Python 3.10/3.11 cez miniforge3.

Stav projektu

Verzia 2.0 (Qt6). Aktívny vývoj. Produkčné nasadenie pre EN→SK dubbing.
